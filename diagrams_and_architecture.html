2. Search Console Drop Geometry Simulator

Toggle between the 4 primary traffic drop shapes identified by Google Search Central to inspect the visual signature and root cause protocols.

Severity: Critical (>50% Collapse)

The Cliff: Sudden Precipitous Drop

Traffic falls vertically within 24 to 48 hours. This shape almost never represents content staleness or gradual competitor improvements. It represents a binary technical failure.
Primary Hypotheses: Site-wide robots.txt blocking, accidental noindex tag injection, DNS resolution failure, or server 5xx outage.
Search Console Action: Immediately inspect URL Inspection tool and Coverage report for crawl blocks. Check Security & Manual Actions tab.
PM Triage Protocol: Coordinate with DevOps/Engineering immediately. File a P0 critical incident ticket before initiating any content edits.
